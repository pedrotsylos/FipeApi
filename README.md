FIPE API 

API REST desenvolvida em C# e ASP.NET Core para consulta de informações de veículos da Tabela FIPE.

Tecnologias
- C#
- ASP.NET Core
- REST API
- HttpClient
- Swagger
- JSON
  
Funcionalidades
- Consulta de marcas
- Consulta de modelos
- Consulta de anos
- Consulta de valores FIPE
- Integração com API externa
